# 日历贴纸可见下沿对齐独立复核

2026-10-15。读取当前 DayCell 的倍率和 offset，逐张用 Pillow 获取 alpha > 20/255 的可见 bbox。只审查，没有修改产品代码。目标为所有贴纸最底可见像素下边界在单格 y=65 pt，不采用主体中心或视觉重心。

## 结论

当前仍未齐底。现有 offset 只对咖啡、打火机、羽毛笔向上2 pt，想起一个人向左上1 pt；其余没有位移。应使用下方动态公式计算每张最终 y offset，替换当前光学 y offset，而非叠加。水平 offset 与齐底无关，可单独保留。

## 动态公式

设单格实际宽度为 C，原图尺寸为 W×H，可见 bbox 下边界为 b（Pillow bbox 的 bottom 是最底可见像素之后的边界），当前图片倍率为 S。静止状态图片框中心为单格 y=53 pt。

```swift
let fittedPixelScale = min(min(50, cellWidth) / imageWidth, 26 / imageHeight)
let visibleBottomFromCenter = (alphaBottom - imageHeight / 2) * fittedPixelScale * artworkScale
let finalYOffset = 65 - (53 + visibleBottomFromCenter)
```

必须传入 GeometryReader 的实际 cellWidth；不能固定使用402 pt屏宽的表中位移。若只要求动画结束齐底，使用静止倍率即可；若出现动画过程也要求齐底，公式还应乘 revealScale，再在 scaleEffect 后应用计算出的 offset。
